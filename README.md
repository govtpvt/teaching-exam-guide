# Teaching Exam Guide

How government teacher recruitment works in India: eligibility tests first, recruitment second. Published by [Govtpvt](https://govtpvt.com/).

Live site: https://teaching-exam-guide.govtpvt.deno.net/

## Pages

| File | Covers |
|---|---|
| `index.html` | CTET and state TETs, PRT / TGT / PGT posts, college-level eligibility |
| `tet-explained.html` | Papers, qualifying marks, validity and where each certificate is accepted |
| `net-and-set.html` | UGC NET compared with state eligibility tests |
| `main.ts` | A small Deno server that serves the three pages |

## The one thing to remember

Passing a TET, NET or SET makes you eligible to apply. It is not an appointment. Vacancies are advertised separately and need their own application.
